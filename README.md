# Fundamental Analysis Based Stock Screener

A web-based stock screening tool designed to filter stocks based on **fundamental analysis strategies**.

## Features

* Import stock data from **Excel or CSV**
* Filter data by **year or quarter**
* Screen stocks using different strategies:

  * Value
  * Dividend
  * Quality
  * Financial Distress
  * Growth
  * Momentum
  * CANSLIM
  * Cyclical
* Set custom filters for **P/E, P/B, ROE, and ROA**
* Combine multiple strategies to narrow down results
* Search and filter stocks by ticker
* View basic financial information and screening results
* Compare selected stocks through charts
* View trends in revenue, profit, ROA, ROE, and cash flow

## Screening Strategies

| Strategy           | Main Focus                                  |
| ------------------ | ------------------------------------------- |
| Value              | Valuation and financial fundamentals        |
| Dividend           | Cash flow and dividend-related indicators   |
| Quality            | Profitability and business quality          |
| Financial Distress | Basic financial health indicators           |
| Growth             | Revenue and profit growth                   |
| Momentum           | Recent improvement in financial performance |
| CANSLIM            | Growth and profitability indicators         |
| Cyclical           | Changes in business performance             |

## Dashboard

The dashboard provides visual comparisons of selected stocks, including:

* Financial indicators
* ROA and ROE
* Cash flow
* Revenue and profit trends
* Stock comparisons through charts

## Tech Stack

* **HTML**
* **CSS**
* **JavaScript**
* **Chart.js**
* **SheetJS**

## How to Use

1. Open `base_stock_screener.html` in a browser.
2. Upload an Excel or CSV file containing stock data.
3. Select the reporting period.
4. Choose one or more screening strategies.
5. Run the screening.
6. Review the filtered stocks and dashboard.
